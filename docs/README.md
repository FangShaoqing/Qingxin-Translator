# Qingxin Translator 开发文档索引

## 项目简介

**Qingxin Translator（青欣翻译）** 是一款本地自用翻译工具，基于在线AI大模型API翻译，提供划译、快捷翻译等便捷功能。

## 快速参考

### 核心功能

- 在线翻译（AI大模型API）
- 划译（选中文本 + 快捷键）
- 快捷翻译（全局快捷键呼出输入框）
- TTS发音（浏览器内置语音合成）
- 历史记录与收藏夹
- 系统托盘常驻

### 技术栈

- Python 3.8+
- pywebview 6.x
- SQLite + Peewee ORM
- PyInstaller

### 配色方案

- 主色：樱花粉 `#FADADE`
- 背景：纯白 `#FFFFFF`
- 辅助：浅灰 `#F5F5F5`
