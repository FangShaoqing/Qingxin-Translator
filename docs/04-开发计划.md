## 五、技术栈

| 组件 | 选型 |
|------|------|
| 语言 | Python 3.8+ |
| GUI框架 | pywebview 6.x |
| 翻译引擎 | AI大模型API |
| TTS | 浏览器内置语音合成 |
| 数据库 | SQLite + Peewee ORM |
| 全局快捷键 | pynput |
| 打包 | PyInstaller |

## 六、风险与应对

| 风险 | 影响 | 应对方案 |
|------|------|----------|
| API连接失败 | 翻译不可用 | 提供连接测试功能，显示错误信息 |
| 全局快捷键冲突 | 快捷键不生效 | 提供快捷键自定义 |
| pywebview兼容性 | UI显示异常 | 使用标准HTML/CSS |
| PyInstaller打包问题 | exe无法运行 | 逐步排查依赖 |
