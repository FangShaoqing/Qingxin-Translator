# Qingxin Translator（青欣翻译）需求文档

## 一、项目概述

本地自用翻译工具，基于在线AI大模型API翻译，提供划译、快捷翻译等便捷功能。

---

## 二、核心翻译功能

| 项目 | 说明 |
|------|------|
| 翻译引擎 | AI大模型（用户填写URL+API Key） |
| 源语言识别 | 自动识别 |
| 主要语言 | 中英互译 |

---

## 三、翻译触发方式

| 方式 | 说明 |
|------|------|
| 划译 | 选中文本 → 按快捷键 → 弹出翻译结果 |
| 快捷翻译 | 全局快捷键 → 弹出输入窗口 → 输入/粘贴内容翻译 |
| 触发模式 | 两种都支持，可配置切换 |

---

## 四、翻译结果展示

- 弹出小窗口显示原文+译文
- 点击其他地方自动关闭
- 可钉住窗口，钉住后不自动关闭

---

## 五、附加功能

| 功能 | 说明 |
|------|------|
| TTS发音 | 浏览器内置语音合成 |
| 复制译文 | 一键复制译文到剪贴板 |
| 收藏/书签 | 收藏常用翻译，可分组管理 |
| 历史记录 | 保存翻译历史，支持查看/搜索 |

---

## 六、系统功能

- 关闭窗口时最小化到系统托盘继续运行
- 开机自启可选配置
- 全部快捷键可自定义

---

## 七、界面与主题

- 界面语言跟随系统语言
- 支持亮色主题

---

## 八、技术栈

| 组件 | 选型 |
|------|------|
| 语言 | Python 3.8+ |
| GUI框架 | pywebview 6.x |
| 翻译引擎 | AI大模型API |
| TTS | 浏览器内置语音合成 |
| 数据存储 | SQLite + Peewee ORM |
| 全局快捷键 | pynput |
| 打包 | PyInstaller |

---

## 九、安装方式

- 打包成exe安装包，双击安装
