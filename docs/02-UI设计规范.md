# Qingxin Translator UI 设计规范

## 一、整体风格

| 项目 | 规范 |
|------|------|
| 设计风格 | 简约现代风格，轻量优雅 |
| 主色调 | 纯白 `#FFFFFF` + 樱花粉 `#FADADE` |
| 辅助色 | 浅灰 `#F5F5F5`、深灰 `#333333`、错误红 `#FF4D4F`、成功绿 `#52C41A` |
| 圆角 | 8px~12px |
| 阴影 | 轻微阴影，增加层次感 |
| 分隔线 | 1px浅灰色 `#E8E8E8` |

---

## 二、字体

| 用途 | 字体 | 字号范围 |
|------|------|----------|
| 中文 | HarmonyOS Sans SC / PingFang SC | 12~16px |
| 英文 | Inter | 12~16px |
| 等宽 | JetBrains Mono | 12~14px |

---

## 三、图标

| 类型 | 风格 |
|------|------|
| 功能图标 | 简约线性图标 |
| 应用图标 | 简约线性，樱花粉主色调 |

---

## 四、动画效果

| 场景 | 动画 |
|------|------|
| 窗口弹出/关闭 | 淡入淡出（300ms） |
| 翻译加载中 | 文字显示"翻译中..." |
| 悬浮效果 | 元素上浮 + 阴影加深 |

---

## 五、主界面布局

```
┌─────────────────────────────────────┐
│     [翻译] [历史] [设置]    ─ ×     │  ← 标题栏
├─────────────────────────────────────┤
│                                     │
│         ┌───────────────┐           │
│         │  翻译输入区域  │           │
│         └───────────────┘           │
│                                     │
│         ┌───────────────┐           │
│         │  翻译结果区域  │           │
│         │    [📋][🔊]   │           │
│         └───────────────┘           │
│                                     │
└─────────────────────────────────────┘
```

- 主窗口用于快捷翻译输入
- 历史记录、设置用页面切换

---

## 六、历史记录页面

```
┌────────────────────────────────────────┐
│ [搜索框🔍]                      [清空] │
├────────────────────────────────────────┤
│ 2026-08-14 16:00                       │
│ 原文：Hello World                      │
│ 译文：你好世界              [📋][🗑️]  │
├────────────────────────────────────────┤
│ 2026-08-14 15:55                       │
│ 原文：Good morning                     │
│ 译文：早上好                [📋][🗑️]  │
└────────────────────────────────────────┘
```

- 列表形式，倒序排列
- 支持搜索
- 每条记录显示：时间、原文、译文、操作按钮

---

## 七、设置页面

```
┌────────────────────────────────────────┐
│ 通用                                   │
│ ─────────────────────────────────────  │
│ 自动复制译文                    [开关] │
│ 最小化到托盘                    [开关] │
│ 快捷键                     [Ctrl+Shift+M] │
├────────────────────────────────────────┤
│ 翻译引擎                               │
│ ─────────────────────────────────────  │
│ API URL    [请输入API URL           ] │
│ API Key    [请输入API Key         ] 👁│
│ 模型名称   [下拉选择] [模型列表][测试连接]│
└────────────────────────────────────────┘
```

### 设置项

| 分类 | 设置项 |
|------|--------|
| 通用 | 自动复制译文、最小化到托盘、快捷键 |
| 翻译引擎 | API URL、API Key、模型名称 |

---

## 八、翻译引擎配置

```
API URL:    用户输入API地址
API Key:    用户输入API密钥（可显示/隐藏）
模型名称:   下拉菜单，点击"模型列表"按钮刷新
测试连接:   验证API配置是否正确
```

---

## 九、窗口行为

| 场景 | 行为 |
|------|------|
| 窗口大小 | 根据页面自适应 |
| 翻译页面 | 较小窗口（约280px高度） |
| 历史记录页面 | 较大窗口（约450px高度） |
| 设置页面 | 中等窗口（约420px高度） |
| 最小化到托盘 | 关闭时隐藏到系统托盘 |

---

## 十、配色方案

| 颜色 | HEX值 | 用途 |
|------|-------|------|
| 粉色主色 | #FADADE | 边框、按钮背景、文字 |
| 粉色浅 | #FFF0F2 | 高亮背景 |
| 背景色 | #FFFFFF | 白色背景 |
| 卡片背景 | #F5F5F5 | 浅灰色 |
| 文字主色 | #333333 | 标题、正文 |
| 文字次要 | #666666 | 译文、说明 |
| 文字辅助 | #999999 | 时间戳、占位文字 |
