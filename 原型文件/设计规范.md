# Qingxin Translator 设计规范

## 技术栈

- **前端**: 原生 HTML/CSS/JavaScript
- **后端**: Python 3.8+
- **GUI框架**: pywebview 6.x
- **数据库**: SQLite (Peewee ORM)
- **翻译引擎**: OpenAI兼容API (LLM)
- **打包工具**: PyInstaller

## 1. 主页面

### 标题栏
- **高度**: 48px
- **背景**: 白色 (#FFFFFF)
- **布局**: 水平居中
- **组件**:
  - 导航图标（3个）：居中，间距 8px
    - 翻译图标（"文A"）：粉色背景 (#FADADE)，白色图标，圆角 8px
    - 历史图标（🕐）：灰色图标
    - 设置图标（⚙️）：灰色图标
  - 窗口控制：右侧
    - 最小化（—）：灰色图标
    - 关闭（×）：灰色图标
- **动效**:
  - 导航图标悬浮: 上浮1px + 背景变化（0.18s）
  - 激活态切换: 平滑过渡（0.2s）

### 输入框
- **初始高度**: 约 60px（两行文本高度）
- **背景**: 浅灰色 (#F5F5F5)
- **边框**: 粉色 (#FADADE) 1px
- **圆角**: 10px
- **占位文字**: "请输入文本"
  - 颜色: 粉色 (#FADADE)
  - 字号: 14px
- **内边距**: 12px
- **动效**:
  - 聚焦: 边框颜色过渡 + 微发光效果（0.15s）
  - 输入: 无特殊动效，保持轻量

### 译文展示区域
- **显示条件**: 用户输入原文后自动显示
- **初始状态**: 收起不展示
- **展开动画**: 输入时使用 fadeInUp 动画渐入（时长 0.3s，cubic-bezier(.2,.8,.2,1)）
- **高度限制**: 最小 80px，最大 200px，超出部分可滚动
- **样式**:
  - 背景: 白色 (#FFFFFF)
  - 边框: 粉色 (#FADADE) 1px
  - 圆角: 10px
  - 内边距: 12px
  - 译文字号: 14px
  - 译文颜色: 灰色 (#666666)
- **操作按钮**:
  - 复制按钮: 点击复制译文到剪贴板
  - 朗读按钮: 使用浏览器语音合成朗读译文

### 交互逻辑
- **自动翻译**: 用户输入原文后自动触发翻译，无需点击按钮
- **语言识别**: 内置自动识别，仅支持中英互译
  - 输入中文 → 自动翻译为英文
  - 输入英文 → 自动翻译为中文
- **窗口高度**: 无输入时窗口较小（约 120px 总高度），有输入时自动扩展显示译文区域
- **窗口宽度**: 约 350-400px（固定）

## 6. 交互流程

### 主页面交互
1. 应用启动显示主页面，窗口较小（约120px高度）
2. 用户在输入框输入原文
3. 系统自动识别语言（中/英）
4. 自动翻译并显示译文（窗口向下扩展，译文区域使用 fadeInUp 动画渐入）
5. 用户可随时通过导航栏切换到其他页面

### 历史记录交互
1. 点击历史图标切换到历史记录页面（淡入淡出过渡 0.3s）
2. 显示所有翻译历史，按时间倒序排列（列表项使用交错入场动画）
3. 用户可搜索、复制或删除记录
4. 点击"清空"按钮可一键清空所有记录

### 设置页面交互
1. 点击设置图标切换到设置页面（淡入淡出过渡 0.3s）
2. 上下滑动浏览所有设置项
3. 通用设置: 切换开关（平滑过渡 0.2s）、设置快捷键
4. 翻译引擎设置: 配置API信息、选择模型、测试连接（按钮加载时显示脉冲动画）

### 数据流
```
用户输入 → 自动识别语言 → 调用翻译API → 显示译文 → 保存到历史记录
                        ↑
                   读取设置中的API配置
```

### 全局交互模式
| 交互类型 | 效果 | 时长 | 缓动函数 |
|----------|------|------|----------|
| 悬浮反馈 | 元素上浮 + 阴影变化 | 0.18-0.25s | ease / cubic-bezier(.2,.8,.2,1) |
| 点击反馈 | scale(0.98) 缩放 | 0.1s | ease |
| 焦点样式 | 边框发光 | 0.15s | ease |
| 页面切换 | 淡入淡出 | 0.3s | cubic-bezier(.2,.8,.2,1) |
| 入场动画 | fadeInUp + 交错 | 0.5s | cubic-bezier(.2,.8,.2,1) |
| 加载状态 | 脉冲动画 | 2.2s | ease |

## 7. 全局快捷键

### 实现方式
- 使用 pynput 库监听全局键盘事件
- 快捷键配置保存在 config.json 中
- 应用启动时自动注册快捷键

### 快捷键格式
- 格式: `修饰键+修饰键+主键`，如 `Ctrl+Shift+M`
- 支持的修饰键: Ctrl、Shift、Alt、Cmd/Win
- 支持的主键: 任意字母、数字、功能键、特殊键

### 窗口切换
- 触发快捷键时，如果窗口可见则隐藏，如果隐藏则显示
- 显示窗口时会自动聚焦
